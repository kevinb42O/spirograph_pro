1. Open the Pattern Generator dropdown
2. Select **"GalacticNexus"** from the list
3. Click **"✦ GENERATE"** button

### Recommended Settings
```
Number of Points: 1000-2000 (higher = more detail)
Radius: 5.0 units
Frequency A: 5 (Fibonacci)

Generate 3D: TRUE (enables Star Tetrahedron)
Height Amplitude: 3.0 units

Phase: 0.0
```
