# 🚀 Quick Start: Generate Galactic Nexus Pattern

## Method 1: Using the UI (Recommended)

1. **Open Unity** and load your SpiroGraph project

2. **Find the Pattern Generator UI** on the left side of the screen

3. **Navigate to** "Pattern Generator" section (Environment panel)

4. **Click the dropdown** - it will show all available patterns

5. **Scroll down** and select **"GalacticNexus"**

6. **Click "✦ GENERATE"** button

7. **BOOM!** 🌌 Watch your agents trace the most epic pattern ever created!

## Method 2: Via Script (For Testing)

If you want to manually create it in the scene:

1. Create empty GameObject: `GameObject > Create Empty`
2. Rename it: `"GalacticNexusTest"`
3. Add component: `GeometricPatternGenerator`
4. In Inspector, set:
   - Shape Type: `GalacticNexus`
   - Number of Points: `1000`
   - Radius: `5`
   - Frequency A: `5`
   - Frequency B: `13`
   - Generate 3D: `✓` (checked)
   - Height Amplitude: `3`
   - Height Frequency: `7`
   - Draw Gizmos: `✓` (checked)
   - Draw Connections: `✓` (checked)
5. Right-click on component > `Generate Pattern`

## Troubleshooting

**Pattern looks too small?**
- Increase `Radius` to 10 or 15

**Too many/few points?**
- Adjust `Number of Points` (500-2000 range)

**Want more spirals?**
- Increase `Frequency A` (try 7, 11, or 13)

**Pattern not generating?**
- Check Unity Console for errors
- Make sure GeometricPatternGenerator script compiled
- Try regenerating UI: SpirographUIManager > Generate UI

**Can't see pattern in Scene view?**
- Make sure `Draw Gizmos` is enabled
- Ensure `Draw Connections` is checked
- Check Gizmos button in Scene view toolbar is ON
