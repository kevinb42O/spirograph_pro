AMAZING LINE RENDERER PREFAB
============================

To create the prefab in Unity:

1. In Unity, create an empty GameObject (Right-click in Hierarchy > Create Empty)
2. Rename it to "AmazingLineRenderer"
3. Add the LineRenderer component (Add Component > Effects > Line Renderer)
4. Add the AmazingLineEffect script (Add Component > Scripts > Amazing Line Effect)
5. Drag the GameObject from Hierarchy to the Prefabs folder

FEATURES:
---------
✨ 3D animated wave pattern with multiple frequencies
🌈 Auto-animating color gradient (cyan → magenta → yellow)
💫 Pulsing glow effect with emission
📊 Smooth width curve (thick to thin)
🎨 High-quality rounded corners and caps (8 vertices each)
⚡ 50 points for ultra-smooth curves
🔄 Adjustable speed, amplitude, frequency, and length

INSPECTOR SETTINGS:
-------------------
Line Settings:
  - Point Count: Number of line segments (default: 50)
  - Amplitude: Wave height (default: 2)
  - Frequency: Number of waves (default: 2)
  - Speed: Animation speed (default: 1)
  - Line Length: Total length (default: 10)

Color Settings:
  - Color Gradient: Custom gradient (auto-generated if empty)
  - Color Speed: How fast colors shift (default: 1)

Width Settings:
  - Width Curve: Width variation along line
  - Max Width: Maximum line thickness (default: 0.5)

Glow Settings:
  - Enable Glow: Toggle emission effect
  - Glow Intensity: Brightness of glow (default: 2)

USAGE:
------
Simply instantiate the prefab in your scene. It will automatically animate!
