### 🚀 Quick Start (30 Seconds)

1. **Add UIManager GameObject** to scene
2. **Add SpirographUIManager component**
3. **Check "Generate UI" checkbox**
4. **Done!** Start creating beautiful patterns

That's it. No manual setup, no configuration, no headaches.

### 💡 Pro Tips

**For Best Results:**
1. Start with a preset (try "Classic" or "Rosette")
2. Adjust one parameter at a time
3. Save configurations you like
4. Use F2 to monitor performance
5. Try different effects with same pattern
6. Experiment with HSV for color harmony

**For Recordings:**
1. Enable Auto Orbit camera
2. Choose appropriate skybox
3. Set to desired effect mode
4. Press Enter to hide UI
5. Record clean spirograph visual

**For Learning:**
